# Hema N - Modern Cyber & Glassmorphic Developer Portfolio 🚀

A high-performance, responsive portfolio website built with modern web technologies for **Hema N** (Computer Science Student & Full Stack Developer).

## ✨ Key Features & "Advanced" Architecture
- **Interactive Particle Matrix Background**: Connected floating nodes that react dynamically to cursor movement on an HTML5 Canvas.
- **Dynamic Typewriter Header**: Automatic rotating titles highlighting your roles (Full Stack, Python, IoT, Academic Honor).
- **Interactive Developer CLI Terminal (`hema@portfolio:~$`)**:
  - Functional command-line interface with commands: `help`, `skills`, `projects`, `education`, `experience`, `certifications`, `contact`, `sudo hire`, and `clear`.
  - Recruiter-friendly interactive command shortcut pills.
- **Synthesized UI Audio Feedback**: Subtle futuristic acoustic clicks powered by the native browser **Web Audio API** (zero external sound files needed, completely toggleable).
- **Interactive Skills Matrix**: Filter categories (All, Languages, Web Tech, Database, Tools) with animated proficiency indicators.
- **Featured Project Showcase (Student Course Registration System)**:
  - Interactive architecture blueprint modal.
  - Live interactive test enrollment simulator button.
  - Code syntax preview of Python Flask backend.
- **Academic & Experience Timelines**:
  - SubZero Technologies Internship highlight.
  - Dr. N.G.P. IoT Workshop and Academic Milestones (CGPA 8.43, HSC 93.3% & 87.3%, SSLC 83.8%).
- **Credentials & Proficiency Award**:
  - Honored Academic Proficiency Award trophy banner.
  - British Council Aptis English, NPTEL IoT, and NCVRT AI/ML certificates.
- **Direct Reach & Instant Connect**:
  - Instant One-Click Copy for Email and Phone numbers.
  - Direct WhatsApp quick chat link (`wa.me`).
  - Interactive form with toast feedback and automatic email drafting.
- **Print-Ready Resume Generator (`resume.html` & Modal)**:
  - Built-in Clean ATS-compliant 1-page printable CV format with print-to-PDF styles.

## 🚀 How to Run & Preview Locally
Simply double-click `index.html` in file explorer to open it in any web browser (Chrome, Edge, Firefox, Brave), or use a lightweight server:

```powershell
# Using Python built-in HTTP server:
python -m http.server 3000

# Then open in browser:
http://localhost:3000
```

## 🌐 Free 1-Click Hosting Options
1. **GitHub Pages**:

2. **Vercel / Netlify**:
